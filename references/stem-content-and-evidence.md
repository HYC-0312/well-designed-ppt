# 理工科 PPT：内容组织与证据选用

在创建或大幅修改理工科演示文稿时使用本参考。它描述决策准则，不预设学科、软件、视觉风格或页数。

## 1. 先建立内容地图

按汇报目的选择主线，通常需要回答：研究或工程问题是什么、采用什么模型或方法、控制了哪些条件、获得什么结果、结果说明什么、结论的适用边界是什么。汇报可以省略不必要的步骤，但不能省略支撑结论的前提。

为每张拟制作的幻灯片写一条简短的页面说明：

| 项目 | 应写清的问题 |
| --- | --- |
| 本页任务 | 听众看完应理解什么？ |
| 核心证据 | 使用哪张原图、数据表、公式、实验记录或软件界面？ |
| 前提 | 哪些条件、单位、坐标、归一化方式会改变解释？ |
| 视觉关系 | 图、公式和解释如何相互对应？ |
| 来源 | 哪些内容来自用户资料，哪些需要外部引用？ |

用户明确要求先规划时，交付可审阅的逐页规划，确认后再执行。用户只要求局部编辑时，以目标页面为中心更新相关说明，不重新组织整份演示文稿。

## 2. 决定图像来源

先判断图像的作用，再决定获取方式：

- **原始证据：** 仪器照片、显微图、软件截图、实验或仿真输出、用户提供的实物图。优先使用原件，保留可验证的轴、刻度、图例、色标和参数。必要裁切不得改变结果含义。
- **解释性示意：** 用于说明几何关系、过程、空间结构或抽象机制。可以生成或绘制，但应与原始证据区分，不能暗示它来自测量或仿真。
- **可编辑数据图：** 当用户需要后续修改数据、坐标或标注时，优先采用可编辑图表或可复现的绘图来源；导出前检查科学标注。
- **软件操作：** 方法步骤需要真实界面证据时，使用已有界面截图。用户要求留空的截图位置，应标明待补内容而不伪造界面。

若用户指定工具或视觉生成流程，遵循该要求；但仍需把真实证据与创作资产分开。

## 3. 从模型走到结论

技术页至少核对下列关系：

1. 符号所指的是标量、向量、复数、幅度、功率、增益还是概率？
2. 每个量的单位和参考基准是什么？“归一化”是相对哪个最大值或基准？
3. 当前结论依赖哪些理想化假设？工程模型是否增加了方向性、损耗、噪声、耦合或边界条件？
4. 数据图展示的量与正文声称的量是否一致？例如幅度与功率的 dB 换算不同。
5. 观察坐标、设备坐标和控制设置是否被混为同一个变量？
6. 比较实验中除目标变量外，其他条件是否真正相同？

数学表达式应在投影尺寸下清晰。复杂推导可分为“定义或假设 → 关键变形 → 最终可读结果”，其余细节放备注或附录。需要 LaTeX 时按数学排版生成并检查最终插入后的大小。

## 4. 组织比较页

同页比较前写明共同基准和唯一改变的条件。对照图保持相近的显示面积与一致的裁切范围；跨图比较颜色时先核对色标是否相同。若两图色标不同，不根据颜色深浅直接推断绝对大小。

让每张图的结论指向可见证据，例如主峰位置、半功率宽度、误差区间、旁瓣、趋势转折或异常点。不要用“显著改善”之类措辞代替可见或计算得到的结果。

## 5. 记录来源

原始数据与外部文献分开记录。对标准、软件行为、技术定义等可核查事实，优先引用原始标准、官方文档或论文；视频可列为讲解来源。若来源仅见于演讲者备注，末页参考文献仍应让观众识别主要依据。未知作者、日期或版本不要猜测。
