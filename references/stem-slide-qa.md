# 理工科 PPT：渲染与技术验收

在交付前使用本参考。自动文件校验只能发现部分结构错误，不能替代对实际投影片的视觉与科学检查。

## 目标页检查

| 检查项 | 可接受状态 |
| --- | --- |
| 页序 | 已按实际幻灯片顺序定位；目录和页脚若需同步，已核对 |
| 标题 | 准确说出本页对象、方法或发现；与图和正文一致 |
| 证据 | 原始图像未被误标为生成图；图题、坐标、单位、图例、色标保留完整 |
| 图像尺寸 | 投影尺寸下能读出关键刻度与图例；同组对照图视觉权重合理 |
| 公式 | 字体足够大；符号、上下标、括号、绝对值与单位正确 |
| 数学逻辑 | 复数、幅度、功率及归一化过程没有跳步或混用 |
| 模型边界 | 理想化假设、实验条件和适用范围与结论放在可关联的位置 |
| 比较 | 共同基准明确；颜色和比例尺可比，或已说明不可直接比较 |
| 文字 | 不遮挡证据；没有不自然换行、编号断裂或过密的说明块 |
| 引用 | 技术事实和外部图源可追溯；自有数据与外部文献分开 |

## 文件级检查

1. 渲染所有改动页面，在统一尺寸下逐张查看；大幅改版时再检查全篇节奏与一致性。
2. 核对文件实际页数、章节顺序、目录和页码标注。页脚数字不能代替实际页面索引。
3. 比较原稿与成品的未改页面，确认没有意外重排、替换字体、丢图或改动数据。
4. 如有可编辑图表或表格，验证它们仍可编辑；如有截图、PDF、公式图片，检查最终嵌入清晰度。
5. 若使用外部资产或文献，检查标题、作者或机构、版本、日期和链接是否与可访问来源一致。无法核实的元数据不要补写。
6. 将测试结果报告给用户：修改范围、关键检查、尚存限制。不要把“成功导出”表述为“已验证科学正确”。

## 优先修复顺序

先修复错误结论、缺失前提、图表不可读、关键证据裁切和公式歧义；再处理排版细节。用户指定的设计取舍优先于通用审美偏好，只要不损害准确性和可读性。
